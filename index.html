📖 CNC NOTE 작성요령

📝 노트 작성 (오른쪽)

내용을 자유롭게 기록하고 맥락이 바뀌면 ✂ 여기서 나누기를 누르세요.

예시)
현황 — PV 800 목표 1,000
니즈 — 파트너 발굴 고민
✂ 나누기 → 새 문단 시작
🔑 핵심 키워드 (왼쪽)

각 문단 작성 후 왼쪽 칸에 핵심 단어·질문을 직접 입력하세요.

예시)
PV 갭 200
파트너 발굴 이슈
다음 미팅 약속
✨ 핵심 요약

전체 내용을 한두 문장으로 압축하고 다음 약속·실행 과제를 적어두세요.

예시)
지인 접촉 재개 필요.
✅ 지인 리스트 10명 작성
✅ 다음 화요일 미팅
💡 성찰

나의 관찰·느낌·개선점을 솔직하게 적으세요. 배움이 행동으로 연결되는 핵심이에요.

예시)
경청보다 조언 먼저 함.
다음엔 니즈 파악 후 제안.
→ 주 1회 연락 실천
💬 작성 순서: 오른쪽 노트 기록 → ✂ 나누기 → 왼쪽 키워드 입력 → 요약·성찰 작성 → 💾 저장

노트를 삭제할까요?
